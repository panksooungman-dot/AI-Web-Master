# 강의영상 자동편집 웹사이트 — 스토리보드

> cnbiz.kr 관리자 시스템의 Design Automation "Storyboard" 기능(`/developer/design/storyboard`)으로
> 자동 생성을 시도했으나, `ANTHROPIC_API_KEY`가 없는 환경이라 실제 프로젝트와 무관한 일반
> 템플릿(홈/회사소개/서비스/문의하기)이 나왔다. 그 결과는 버리고, 실제 구현된 화면을 기준으로
> 이 문서를 직접 작성했다 — 지어낸 내용 없이 `apps/lecture-editor-web` 소스코드 그대로 반영.

## 1. 화면 목록 (Screen List)

| 화면 | 경로 | 접근 조건 | 설명 |
|------|------|-----------|------|
| 로그인 | `/login` | 비로그인 시 자동 이동 | 비밀번호 1개로 로그인 |
| 홈 (업로드) | `/` | 로그인 필요 | 영상 업로드 폼 + 처리 이력 목록 |
| 작업 상세 | `/jobs/[id]` | 로그인 필요 | 진행 상태·검토표·다운로드·수정 요청 |

## 2. 화면 흐름 (Screen Flow)

```mermaid
flowchart LR
    A[/login\n로그인] -->|비밀번호 확인| B[/\n홈: 업로드 + 이력]
    B -->|영상 업로드| C[/jobs/id\n작업 상세]
    C -->|3초마다 상태 폴링| C
    C -->|완료: 다운로드| D[[완성 영상 파일]]
    C -->|수정 지시 입력| C
    B -->|이력 클릭| C
    C -->|뒤로 가기| B
```

## 3. 내비게이션 구조 (Navigation Flow)

```
/login
  └─ 로그인 성공 → redirect 파라미터가 있으면 그 경로로, 없으면 "/"

/  (홈)
  ├─ 업로드 폼 (파일 선택 → 업로드 시작 버튼)
  │    └─ 업로드 완료 즉시 → /jobs/[새 작업 id] 로 자동 이동
  └─ 처리 이력 목록 (최신순)
       └─ 항목 클릭 → /jobs/[해당 id]

/jobs/[id]  (작업 상세, 뒤로 가기 없이 홈으로 직접 돌아가는 링크는 없음 — 브라우저 뒤로가기 사용)
  ├─ 상태 배지 (대기중 → 음성분석중 → 렌더링중 → 완료/오류)
  ├─ [완료 시] 완성 영상 다운로드 버튼
  ├─ [reviewText 있을 시] 검토표 접기/펼치기
  ├─ [완료 시] 수정 요청 입력창 + 버튼
  │    └─ 제출 → 상태가 "수정 반영 중"으로 바뀌며 같은 화면에서 계속 진행 표시
  └─ 처리 로그 접기/펼치기 (디버깅용)
```

## 4. 사용자 여정 (User Journey) — 의뢰자 기준

1. **접속** — 의뢰자가 서버 주소로 접속, 비밀번호 로그인
2. **업로드** — 촬영 원본 파일 선택 후 업로드. 업로드 진행률(%)이 실시간 표시됨
3. **대기** — 업로드 완료 즉시 작업 상세 화면으로 이동. 3초마다 자동으로 상태를 다시 확인하며
   "대기 중 → 음성 분석 중 → 렌더링 중" 순서로 상태 배지가 바뀌는 것을 지켜봄
4. **결과 확인** — 완료되면 "완성 영상 다운로드" 버튼과 "어디를 자르고 줌인했는지" 검토표가 나타남
5. **(선택) 수정 요청** — 마음에 안 드는 부분이 있으면 자연어로 입력
   (예: "3번 구간 자르지 말고 살려줘") → 제출 → 자동으로 재처리 → 완료되면 다시 다운로드 가능
6. **재방문** — 홈 화면의 처리 이력에서 예전에 올린 영상들을 다시 확인 가능

## 5. 화면별 상세 설명 (Screen Description)

### `/login`
- 입력: 비밀번호 1개
- 실패 시: "비밀번호가 올바르지 않습니다." 메시지
- 성공 시: `redirect` 쿼리 파라미터가 있으면 그 경로로, 없으면 홈으로 이동

### `/` (홈)
- 상단: 서비스 소개 한 줄 문구
- `UploadForm`: 파일 선택 input(`accept="video/*"`) + 업로드 버튼, 업로드 중 진행률(%) 표시
- 하단: "처리 이력" — 과거 업로드한 모든 작업을 최신순으로 나열(파일명 + 상태)

### `/jobs/[id]`
- 파일명 + 상태 배지(색상으로 구분: 진행중=파랑, 완료=초록, 오류=빨강)
- 오류 시: 오류 메시지 전체 표시
- 완료 시: 다운로드 버튼(초록, 클릭 시 `.mp4` 다운로드) + 검토표(접기/펼치기, 기본 펼침)
- 완료 상태에서만: 수정 요청 입력창 노출
- 지금까지 적용된 수정 이력 목록
- 처리 로그(접기/펼치기, 기본 접힘) — 타임스탬프별 진행 로그
